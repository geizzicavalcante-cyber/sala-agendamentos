Sistema de Agendamento para Salão de Beleza

Projeto desenvolvido durante o aprendizado em Front-end, com o objetivo de praticar conceitos básicos de React, TypeScript e manipulação de dados no navegador.

O sistema simula a rotina de um salão de beleza, permitindo organizar agendamentos e informações básicas.

🎯 Objetivo do Projeto

Praticar o desenvolvimento de uma aplicação React, trabalhando com:

Criação de componentes

Uso de estado (useState)

Manipulação de listas

Organização de dados

Persistência com LocalStorage

📌 O que o sistema faz

Cadastro de agendamentos

Exibição dos atendimentos em formato de cards

Separação de atendimentos abertos e finalizados

Alteração do status do atendimento

Armazenamento dos dados no LocalStorage

🛠️ Tecnologias Utilizadas

React.js

TypeScript                                                                                                           

HTML5

CSS3

📱 Observações

Projeto sem backend

Dados salvos apenas no navegador

Foco no aprendizado de lógica e React
